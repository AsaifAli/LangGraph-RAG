# Demo Knowledge Base

This directory contains small synthetic documents designed for a recruiter-friendly demo. They contain no real company or personal data.

## Suggested demo flow

1. Seed both documents into local Qdrant.
2. Ask a single-document fact question.
3. Ask a cross-document comparison.
4. Ask an unanswerable question and show the system abstaining.
5. Inspect the evidence/citation QA panel.

The documents intentionally contain a few overlapping topics so the comparison and evidence-quality workflows are visible.
